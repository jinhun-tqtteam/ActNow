# Extension Icons

This folder contains the icons for the ActNow Chrome extension.

## Required Icons:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

## Icon Design Guidelines:
1. **Style**: Clean, modern, and professional
2. **Colors**: Use primary color #6366f1 as the main brand color
3. **Symbol**: Chat bubble or speech bubble with AI elements
4. **Background**: Transparent

## Recommended Design:
- A chat bubble with a brain/ai symbol inside
- Or a speech bubble with "AI" text
- Use gradient effect for modern look

## To Create Icons:
You can use tools like:
- Adobe Illustrator
- Figma
- Canva
- GIMP (free)
- Online icon generators

## Temporary Note:
For now, you can use any placeholder icons. The extension will work with basic square PNG images.
