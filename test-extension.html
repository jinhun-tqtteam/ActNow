ActNow Extension Test Page

📋 Test Instructions

  1. Install the ActNow Chrome extension in developer mode
  2. Navigate to this page
  3. Look for the floating chat button in the bottom-right corner
  4. Try clicking on the chat button - it should open the chat interface
  5. Test the minimize/close functionality
  6. Test the settings button

🔍 What to Check

  • ✓ Chat button is visible in bottom-right corner
  • ✓ Button is clickable (cursor changes to pointer)
  • ✓ Chat interface opens when button is clicked
  • ✓ Console shows "Chat button clicked!" message
  • ✓ No JavaScript errors in console
  • ✓ All buttons and interactions work properly

📝 Test Results

Click the chat button to test the functionality...
If buttons don't work, reload the extension from chrome://extensions/

🐛 Troubleshooting

If the button is not clickable:

  • Check browser console (F12) for JavaScript errors
  • Ensure the extension is properly loaded
  • Try refreshing the page
  • Check if other elements are blocking the button
